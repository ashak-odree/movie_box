# movie_box

TUI-styled web app for `MovieBox-TUI` with `"mamamiakoi"` passphrase gate, live streaming, direct downloads, live FFmpeg HEVC → H.264 HLS transcoding, daily GitHub Actions sync with upstream `MovieBox-TUI`, and automatic deployment to Cloudflare Workers & HuggingFace Spaces.
